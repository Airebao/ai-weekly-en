# AI week in review (EN)

Review AI news from the past seven days, grouped by topic. Use when the user asks for a weekly recap or wants to catch up after a week away.

| | |
|---|---|
| 版本 | `1.7.0` |
| 站点 | [https://aitop.news](https://aitop.news)（AITOP） |
| SkillHub | https://skillhub.cn/skills/user_507a5056/ai-weekly-en |
| 仓库 | https://github.com/Airebao/ai-weekly-en |

## 安装

```bash
skillhub install ai-weekly-en
```

也可以直接把 `SKILL.md` 放进你的 skill 目录——它是完整的 skill 正文，
里面写明了 Base URL、请求头和参数约定。

## 文件

- `SKILL.md` — skill 正文（frontmatter 的 `name` / `description` 即安装入口）
- `_meta.json` — 发布元数据（slug / version / displayName / summary / license / edition）
